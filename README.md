# Готовые задания по Python

Домашки из курса "Python для начинающих". Все файлы лежат по папкам по номеру урока, внутри каждого файла — подробные комментарии, как и что работает.

## Что внутри

- **Урок 1. Введение** — правка кода с `sep` и `end`
- **Урок 2. Переменные и типы данных** — числа, соседние числа, минуты в часы, столы для кабинета, типы данных
- **Урок 3. Ветвление и цикл while** — максимум/минимум, время года, факториал, разбор числа по цифрам
- **Урок 4. Цикл For** — нечётные числа через шаг range, continue, угадай число, единичная матрица
- **Урок 5. Работа со строками** — split, count, isdigit, swapcase, случайные числа
- **Урок 6. Списки и кортежи** — генераторы списков, сортировка, счастливый билет
- **Урок 7. Словари и множества** — словарь переводов, keys/values/items, операции над множествами
- **Урок 8. Функции** — площадь круга, факториал, простые числа
- **Урок 9. Функции. Продолжение** — рекурсия, числа Фибоначчи, map/filter/lambda, декоратор-таймер
- **Урок 10. ООП. Классы** — банковский счёт с пином, класс Person
- **Урок 11. ООП. Наследование** — прямоугольник/параллелограмм/квадрат, Money с исключениями
- **Урок 12. Исключения** — ValueError, ZeroDivisionError, IndexError
- **Урок 13. Модули** — свои модули с одинаковыми именами функций
- **Урок 14. Проверка ошибок и исключений** — ввод месяца с защитой от дурака

## Как запускать

Нужен Python 3. Запуск из консоли:

```
python "Урок 2. Переменные и типы данных/urok2_zadanie1.py"
```

Некоторые задания (угадай число, банковский счёт, словарь студентов) ждут ввода с клавиатуры — это нормально, просто отвечайте на вопросы программы.

Задания из уроков 9, 11, 12 и 13 можно запускать сколько угодно раз — там случайные числа или try/except, ошибки ввода программа ловит сама.
